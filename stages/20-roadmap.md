# Stage 20 — Implementation roadmap

## Work

- Define walking skeleton/proof of architecture, MVP, production hardening, scale-driven improvements, and optional future capabilities.
- For every phase specify scope, tasks, deliverables, dependencies, acceptance criteria, risks, and deliberate postponements.
- Make the walking skeleton prove one realistic request through the important boundaries while allowing temporary internals.
- Tie every milestone to requirements, ADRs, tests, and observable evidence.
- Use `platform_architect` for sequencing and dependency review.

Output: `outputs/stages/20-roadmap.md`.

Gate: an engineering team can start the first milestone; no future-scale component appears in MVP without a requirement.
